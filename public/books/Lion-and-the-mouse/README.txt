FlipForge Studio — Exported Flipbook
====================================

ชื่อ      : ราชสีห์กับหนู เจ้าป่าใหญ่กับเพื่อนตัวเล็ก
จำนวนหน้า : 9
โหมด      : หน้าเดี่ยว
ความเร็ว  : 1700 ms/หน้า
เนื้อกระดาษ: undefined
พื้นหลัง  : slate

โครงสร้างไฟล์
-------------
  index.html
  assets/css/style.css
  assets/js/app.js
  pages/  (ภาพทุกหน้า)
  netlify.toml

วิธี Deploy (ได้ลิงก์แชร์ภายใน 30 วินาที)
---------------------------------------
1) Netlify Drop : เปิด https://app.netlify.com/drop แล้วลากไฟล์ ZIP ลงไป → ได้ URL ทันที
2) Tiiny.host   : เปิด https://tiiny.host อัปโหลด ZIP แล้วกด Launch
3) GitHub Pages : push ทั้งโฟลเดอร์ขึ้น repo แล้วเปิด Pages ที่ Settings

ฟีเจอร์ในตัว
------------
- ปุ่ม Share : คัดลอกลิงก์ / QR Code / โค้ดฝัง iframe / แชร์โซเชียล
- Deep link  : ต่อท้าย URL ด้วย #page=5 เพื่อเปิดที่หน้า 5 โดยตรง
- ปุ่มเสียง  : เปิด/ปิดเสียงกระดาษได้
- คีย์ลัด    : ลูกศรซ้าย/ขวา เปลี่ยนหน้า, Esc ปิดหน้าต่างแชร์

ไม่มีลายน้ำ ไม่มีโลโก้ผู้ให้บริการใดๆ ทั้งสิ้น
